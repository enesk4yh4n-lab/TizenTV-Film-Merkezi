# Güncel tanıtım görüntüleri

`anasayfa.png`, `filmler.png`, `diziler.png` ve `kesfet.png`, 14 Kasım 2026 tarihinde çalışan Tizen 3 WSL emülatörünün gerçek penceresinden doğrudan alındı. WGT 2.0.0 / çekirdek 2.1.5 kullanıldı. Arayüz yeniden oluşturulmadı ve katalog verileri uydurulmadı. Fiziksel TV ekran görüntüsü değildir.

# Kılavuz görselleri

Film Merkezi 2.0.0'ın gerçek paket arayüzü, 1920×1080 yalıtılmış Chromium oturumunda görüntülenmiştir. TV API'leri ve özel dosya alanı test katmanıyla sağlanmıştır. Fiziksel TV görüntüsü veya canlı depo kurulum kanıtı değildir.

İlk kurulum, bilgilendirme, boş depo/ana sayfa, ayarlar, Güncelleme Merkezi ve boş depo arama/adres formları gösterilir. Yeni GitHub deposunun sonucu veya başarılı yüklemesi uydurulmamıştır. Uygulama kaynakları görsel üretmek için değiştirilmemiştir.
